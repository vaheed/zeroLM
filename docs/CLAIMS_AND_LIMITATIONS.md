# Claims and Limitations

## What is claimed (Phases 0-4)
- The repository defines, and CI enforces, what is hand-authored, what may be learned online, and what is prohibited.
- A CPU engine exists: deterministic kernels, four recurrent cells at equal parameter budgets, fixed-size exactly-resumable session state, measured at initialization. The GRU core was selected by a documented, reproducible score.
- Any byte sequence is accepted from the first run (no OOV, malformed UTF-8 located not rejected). Initialization is deterministic and pinned by SHA-256; no tokenizer or embedding asset exists.
- The teaching protocol is observable and traced, and a session provably leaves weights unchanged.
- Baseline reports record commit, clean-tree status, and toolchain; `zerolm-baseline check` rejects dirty or missing provenance.
- Phase 4: after one chronological pass over 40,000 generated bytes, a local delta rule on the readout layer predicts unseen sentences and unseen word combinations at about 2.3 bits/byte, against 8.0 for the same untrained architecture and 4.2 for a byte-frequency baseline (3 seeds, a floor frozen before the main run). A Hebbian rule with no error signal also clears the floor (about 3.3 BPB). Every update is logged and checked against the stream. See `docs/ONLINE_LEARNING.md`.

## What is not claimed
- The Phase 4 learner is weak: a byte trigram baseline beats it by about 1 BPB. Only the readout learns (on frozen random GRU features), on a tiny generated language of about 50 words. It shows online acquisition, not competitive language modeling and not English understanding.
- On a softmax readout, the delta rule equals one single-layer cross-entropy gradient step. It is local (no backpropagation through layers or time) but not gradient-free in a strict sense. The online-BPTT control was not run.
- Forgetting, long streams, and persistent memory are unmeasured. Phases 5-11 are unimplemented.
- `teach`/`ask`/`forget` are served from a session-local ledger, not from model memory or learning. The model does not understand English at bootstrap.
- Bake-off metrics are initialization-time capacity measurements, not language ability, memory capacity, or learning evidence.
- No capability, benchmark score, or "human-level" claim is made.
- Memory is finite; capacity and interference will be measured, not assumed.
- The static scan detects obvious pretrained artifacts and download calls; it cannot prove the absence of every hidden data source.
- Code and data from the removed v0.2 / ZeroLM Next experiments live only in git history; no results from them carry over.
