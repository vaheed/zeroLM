# Claims and Limitations

## What is claimed
- The repository defines, and CI enforces, what is hand-authored, what may be learned online, and what is prohibited.
- A CPU engine exists: deterministic kernels, four recurrent cells at equal parameter budgets, fixed-size exactly-resumable session state, measured at initialization. The GRU core was selected by a documented, reproducible score.
- Any byte sequence is accepted from the first run (no OOV, malformed UTF-8 located not rejected). Initialization is deterministic and pinned by SHA-256; no tokenizer or embedding asset exists.
- The teaching protocol is observable and traced, and a session provably leaves weights unchanged.
- Baseline reports record commit, clean-tree status, and toolchain; `zerolm-baseline check` rejects dirty or missing provenance.
- Online learning: after one chronological pass over 40,000 generated bytes, a local delta rule on the readout layer predicts unseen sentences and unseen word combinations at about 2.3 bits/byte (BPB, bits per byte), against 8.0 for the same untrained architecture and 4.2 for a byte-frequency baseline (3 seeds, a floor frozen before the main run). A Hebbian rule with no error signal also clears the floor (about 3.3 BPB). Every update is logged and checked against the stream. See `docs/online-learning.md`.
- Memory: facts written through the live API persist across process restarts only as tensors in the model checkpoint, and are answered by an attention read over those tensors. On 3 seeds x 1,200 generated facts (with contradictions, supersessions, and deletions), after a restart: exact-key recall and precision 1.000; non-trivial paraphrase recall 0.973 and precision 0.993; 0.6% of negative queries answered. Memory writes leave every core tensor byte-identical; corrupt or interrupted checkpoints fall back to the last valid one; zeroing or permuting memory tensors drops recall to 0. Gates were frozen from pilot seeds. See `docs/memory-format.md`.
- Reasoning: statements of a bounded language are stored as bound role-filler phasor vectors in a tensor memory, and new questions are answered by eight controlled operators (class inclusion, transitivity, inheritance with exceptions, comparison, arithmetic by number binding, temporal order, negation, conditionals) built from vector probes, unbinding, and cleanup. On 3 seeds plus a hidden seed (about 525 questions each, 20 categories), answers agree with a symbolic reference on every question; a verbatim-lookup baseline gets 0% of the derived questions. Removing one proof premise changes answers exactly as the reference says (40/40 per seed), the reported premises alone reproduce each answer, and disabling any operator or the binding, discourse-state, or retrieval pathway removes exactly the inferences that depend on it. See `docs/reasoning.md`.

- Uniform engine (complete): a neural ISA (instruction set architecture: the project's fixed list of tensor operations, see `docs/neural-isa.md`: matvec, gate, norm, bind, top-k, hash_rows, delta_write, step) runs programs compiled by `zerolm-wsp` (WSP = weight-space programming) from typed circuit specs in `model/prog/` (output hashes pinned; patches apply and revert to the original hash). Memory now runs only as compiled programs: `memory-encode` turns raw key and query bytes into the key and word vectors (bit-identical to the former host encoder, by unit test), and `memory-read` answers. The frozen memory gate passes unchanged through both on 3 seeds, an independent reference interpreter reproduces all 8,700 gate queries per seed bit for bit from the two exported bundles, and zeroing a circuit block removes exactly what it carries (read verification: exact answers kept, every negative accepted; attention, selection, cleanup, or the encoder's byte classes, windows, or segmentation: recall 0; the encoder's case folding: upper-cased queries recall 0, while lower-case recall stays about 0.83 because interior trigrams need no folding). Reasoning's graph search also runs as compiled circuits (C5 decodes the relation memory, C6 computes reachability and shortest proofs), and the uniform-engine gate replays every circuit run behind a generated world's questions on the reference interpreter, including runs with operators ablated: 3,520 of 3,520 bit-exact (also the encoder runs made while the world is taught). The reasoner's one-step probes, symbol cleanup, pronoun resolution, and the bundling of a new statement run in two more circuits (`relation-probe`, `symbol-cleanup`). Symbol, role, and relation vectors are now computed by a fifth compiled circuit (`atom-encode`: salted hashes of the name bytes into a seeded table, normalized to unit phasors and bound), no longer by a host random generator. Memory values are encoded and written to and recalled from fast weights by compiled circuits (`value-encode`, `fast-write`, `fast-recall`), so the host value decoder and fast-weight code are gone. Numbers are encoded and decoded by two more compiled circuits (`number-encode`: the bytes of a decimal numeral to a product of seeded digit phasors; `number-decode`: cleanup by a codebook `matvec` and top-1), no longer by host trigonometry and a host scan. The eight operators' decisions are compiled circuits too (negation joins, inheritance levels, rule chaining, counts by phasor arithmetic, and the verdict), and the reasoning gate still agrees with the reference on every question. The reasoner's writes are decided by circuits as well: `relation-probe` decides whether a statement is stored (subject resolved, not a duplicate) and computes its slot and metadata rows and the next discourse state, and `symbol-cleanup` decides whether a name is new and gives its codebook row; the host only appends those rows at its counters. The memory store's writes are decided by four more circuits (`memory-write` for teach, correct, and confirm; `memory-forget`, which follows supersession links; `memory-compact`, which orders and remaps slots; `memory-history`), and the host only stamps, checks capacity, and moves the rows they specify. The bounded-language parser now tokenizes and folds bytes through `language-lex`: its ordered byte spans and continuation bit support words across 128-byte chunks without truncation. Phrase normalization now runs through generic `row-lookup` and recurrent `sequence-rewrite` circuits. The existing hand-written lexical and rewrite prior is explicit, separately hash-pinned `bootstrap_grammar` seed data in `model/bootstrap/reasoning-grammar.json`, stored in the checkpoint and verified on load; it is not compiler output or learned grammar. Bounded template matching, question detection, numeral parsing, and token equality now run in generic compiled programs over 115 frozen seed templates and external lexical, numeric, and Unicode whitespace tables. Typed frame binding is the compiled `frame-bind` circuit (role fillers, filled roles, codebook entries, polarity, relation vectors bound with a dimension or counted thing); the host only copies the rows its masks select and uses its form code to pick a fixed circuit sequence. The gate's pending list is empty: all 141,941 reasoning circuit runs and 862 memory runs replay bit for bit, with 0 host-audit violations. See `docs/neural-isa.md`.

- Real-text data and baselines (in progress, not complete): a manifest of public-domain Project Gutenberg books in two sources (33 fiction, 23 non-fiction) with licenses and hashes, whole-document splits, a verified fetch script, an n-gram contamination check, BLiMP (67,000 pairs) and LAMBADA (5,153 passages) harnesses over hashed CC BY 4.0 files, and baselines on held-out books: Kneser-Ney order 5 about 2.17 bits per byte (BPB) at 12.5 million exposure bytes, byte 5-gram models near chance on BLiMP (0.51-0.52) and 0% on LAMBADA. Level thresholds are frozen in `model/specs/levels.json` (not yet checked against their published sources). See `docs/data.md`.
- Representation feasibility (Gate A), main run: **FAIL / PIVOT for the primary local rule at this scale.** On 3 seeds and a hidden split, after 10^7 bytes, e-prop (eligibility propagation with fixed random feedback) improved a fresh readout's held-out BPB over random features by 0.010 (not significant), while the same architecture trained by backpropagation through time (a CONTROL, excluded from strict results) improved it by 1.37 BPB: local learning captured 0.7% of the available gain. A matched random perturbation gained nothing, and all validity checks held. The project lead chose to allow single-pass online gradient learning in the mainline (constitution invariant 4 amended 2026-11-26). The rerun with that rule on fresh held-out books and new seeds **passed**: after 10^7 bytes it improved a fresh readout's held-out BPB over random features by 1.55 (per seed 1.36, 1.45, 1.83), reached 2.71 end-to-end BPB against 4.52 for byte frequency, kept 95% of its first-source gain after a domain shift, and every one of its 312,500 updates per seed is logged and verified. It is still 0.6 BPB behind Kneser-Ney order 5 (2.10), so no language-model level above L0 is claimed. See `docs/representation-learning.md` and `research/decisions/gate-a-2026-11-26.md`.
- Novelty review (revision 1, 2026-11-26): no novelty claim is made. A literature review (`docs/novelty-analysis.md`) finds each mechanism (compiled weights, match models, fast weights, Hopfield retrieval, caches, online gradient learning) in prior work. The pre-registered comparison that could support a claim (a trainable compiled circuit against random initialization at equal data and compute, `docs/experimental-design.md`) has not been run. Experiment N0 on the development role: a match-model prior adds 0.011 BPB over Kneser-Ney 5 on fiction and 0.148 on non-fiction at 10^7 exposure bytes (hidden role unread), and a first mixer version lost up to 0.11 BPB. Experiment N1 sets the conventional bars at 10^6 exposure bytes (development role, 3 GRU seeds): an online GRU alone 2.71 / 2.96 BPB, Kneser-Ney 5 2.22 / 2.35, the GRU-plus-count mixture (G) 2.20 / 2.32, and G plus a match model (H) 2.14 / 2.18 (fiction / non-fiction); the GRU adds only about 0.03 BPB to count-plus-match. These are controls, not ZeroLM-specific results. Outcome so far: INCONCLUSIVE for the central hypothesis.

## What is not claimed
- Compiled phrase normalization currently executes rewrite steps per token and per rule, adding interpreter overhead. In a single local before/after run, per-seed median reasoning-question latency was approximately 13–19 ms versus 9–11 ms; these measurements can vary with machine load.
- After circuit-based grammar recognition, a single local run measured per-seed median reasoning-question latency of approximately 16–23 ms, compared with 13–19 ms in the preceding normalization-stage run. These are uncontrolled local measurements, not a performance guarantee.
- The online learner is weak: a byte trigram baseline beats it by about 1 BPB. Only the readout learns (on frozen random GRU features), on a tiny generated language of about 50 words. It shows online acquisition, not competitive language modeling and not English understanding.
- On a softmax readout, the delta rule equals one single-layer cross-entropy gradient step. It is local (no backpropagation through layers or time) but not gradient-free in a strict sense. The online-BPTT (backpropagation through time) control was not run.
- Catastrophic forgetting in the online learner and long streams are unmeasured. The real-text and representation-feasibility milestones are in progress and not complete; the scalable-core and scaling milestones are not started. In particular, the shipped online predictor and memory still use frozen random embedding and recurrent core; the learner that builds representations (online truncated BPTT) exists only as the Gate A research arm and has not been ported into the mainline checkpoint or the neural ISA (Phase 10). The local rule tried at Gate A (e-prop) did not work at this scale. The shipped online predictor is also worse than byte frequency on real text (about 4.8 against 4.5 BPB), because its constants were tuned on a generated language. No ZeroLM model reaches any language-model level above L0 on real text; the best count baseline is a reference, not a ZeroLM result.
- Memory is slot-addressed storage with a programmed, not learned, retrieval computation. Its key encoder is a frozen bag of hashed byte trigrams: it ignores word order and has no synonymy. The facts are generated pseudo-word triples. It shows persistent weight-resident storage and retrieval, not understanding, reasoning, or memory learned from experience. fast weights is small (about 0.75 recall at 32 associations). Each save rewrites a 24 MB checkpoint (about 1 s). Memory does not yet influence next-byte prediction.
- Reasoning is programmed, not learned: the grammar and every operator's control flow are hand-written, and agreement with the symbolic reference is by construction. The test language is bounded with pseudo-word content; it is not open-domain understanding. Exclusion is directional, there is no modus tollens, and "it" means only the most recent subject. The reasoner is not yet connected to the online learner or to generation.
- `zerolm run` serves `teach`/`ask`/`forget` from a session-local ledger, not from model memory. `zerolm memory --dir DIR` serves them from weight-resident memory. Neither involves understanding English.
- Bake-off metrics are initialization-time capacity measurements, not language ability, memory capacity, or learning evidence.
- No capability, benchmark score, or "human-level" claim is made. The roadmap revision 2 language-model levels (L1-L4) and the 1.0 target (L3) are goals, not results; the current system is Level L0.
- Uniform execution (constitution invariant 10) is met for memory and reasoning: the gate's host audit finds no text processing on the model path and its pending list is empty. The host still sequences fixed circuit pipelines from emitted form and predicate codes and copies bytes and masked rows, and the checks are bit-parity with the reference interpreter plus block ablations, not proof that no behavior hides in host glue. The memory circuits are hand-compiled algorithms, not learned; the encoder's byte classes are ASCII protocol constants, and neither circuit has been through the byte-permutation test. Keys and queries are limited to 254 bytes. With the circuits and their reference-parity and ablation checks, the memory gate takes about 10 minutes instead of about 1.
- Memory is finite; capacity and interference will be measured, not assumed.
- The static scan detects obvious pretrained artifacts and download calls; it cannot prove the absence of every hidden data source.
- Code and data from the removed v0.2 / ZeroLM Next experiments live only in git history; no results from them carry over.
